# Yelp content for Fin and Fin Copilot

Add each article in Fin: **Knowledge (Train) → Content → New → Internal article** (or Public article where marked),
paste the text, publish, then select the articles and choose **Change Fin Copilot state → Enable for Fin Copilot**.
Internal articles are for agents and Copilot only; public ones can also be used by the Fin AI Agent in the Messenger.
